# 期貨題庫刷題網站

一個離線、免安裝的期貨業務員考古題刷題工具。把官方歷屆試題 PDF 轉成單一網頁檔 `index.html`，**雙擊就能用**，不需要網路、不需要架伺服器。已收錄 113 年起的歷屆試題，提供初階（自選年份／科目／題數）、進階（法規 50＋理實 50 模擬考）、錯題本與歷史紀錄等功能。

---

## 檔案說明

| 檔案 | 用途 | 誰會用到 |
|------|------|----------|
| `index.html` | 最終成品，刷題就開這個 | 所有人（雙擊即用） |
| `xxxxx.pdf` / `xxxxxa.pdf` | 原始考古題（題目／答案） | 維護題庫時 |
| `build.py` | 轉檔腳本：把 PDF 解析後內嵌進 HTML | 維護題庫時 |
| `template.html` | 網頁版型（`build.py` 會把題庫注入它）。**請勿刪除** | 維護題庫時 |
| `更新題庫.bat` | 一鍵重跑 `build.py` | 維護題庫時 |

> 一般使用者只需要 `index.html` 一個檔。題庫資料已經內嵌在裡面，所以可以單獨複製給別人用。

---

## 如何更新題庫（加入新的考古題）

### 步驟

1. **準備兩個 PDF**：一份題目檔、一份答案檔。
2. **照命名規則改檔名**後，丟進這個資料夾。
3. **雙擊 `更新題庫.bat`**，等它跑完。
4. 完成。新年份會自動出現在初階的年份選單，也會自動併入進階題庫。

過程中**完全不需要改任何程式碼**。

### 命名規則

檔名格式為 `民國年(3碼) + 第幾次(2碼)`，答案檔在後面多一個 `a`：

| 考試 | 題目檔 | 答案檔 |
|------|--------|--------|
| 114 年第 1 次 | `11401.pdf` | `11401a.pdf` |
| 114 年第 2 次 | `11402.pdf` | `11402a.pdf` |
| 115 年第 1 次 | `11501.pdf` | `11501a.pdf` |
| 115 年第 2 次（新增範例） | `11502.pdf` | `11502a.pdf` |

> 題目檔裡需同時包含「期貨交易法規」與「期貨交易理論與實務」兩科（官方原始試題即為此格式），各 50 題。

### 跑完後會看到什麼

`更新題庫.bat` 會顯示每個 PDF 的解析結果，例如：

```
  11502  期貨交易法規     50 題  ✓
  11502  期貨交易理論與實務  50 題  ✓
========================================================
題庫解析完成：8 次考試 / 800 題   ← 範例：此為「加入 11502 後」的示意
...
已寫入 index.html
```

> ⚠️ 上面的 `8 次 / 800 題` 只是「假設新增 11502」的示意數字，**不代表目前題庫**。實際題數依你已收錄的年份而定，並以網頁首頁顯示的數字為準（例如目前收錄 113～115 年共 7 次、700 題）。

只要每個科目都是 `✓`、最後出現「已寫入 index.html」就成功了，直接拿 `index.html` 來用即可。

> 某些年份版面較特殊時，會多印一行如「（11301 排版：題目=raw、答案=layout）」，這是腳本自動選用的解析模式，**屬正常訊息、不是錯誤**。

## 環境需求（只有維護題庫時需要）

重跑 `build.py` 需要這台電腦有：

- **Python 3**（本機已安裝 3.12）
- **pdftotext**（poppler 工具，本機已安裝）

> 純粹刷題的人不需要這些，他們只要 `index.html`。

## 疑難排解

| 狀況 | 原因與處理 |
|------|-----------|
| 顯示 `✗ 解析失敗`（例如某題找不到選項） | 腳本已自動嘗試多種排版模式（layout／raw／default），全部失敗才會報錯，並指出是哪一份、哪一科、第幾題。通常代表該 PDF 非官方原始檔或版面異常；換回官方原始檔多半即可解決。不會默默產生錯題。 |
| 答案對不上（驗證失敗） | 答案檔的格狀表排版異常。確認答案檔是官方原始檔、未被重新編輯過。 |
| 雙擊 `.bat` 閃一下就關 | 直接在該檔上點右鍵 → 編輯，或在終端機手動執行 `python build.py` 看完整錯誤訊息。 |
| 換了新電腦無法更新 | 新電腦需先安裝 Python 3 與 pdftotext（poppler）。刷題本身不受影響。 |

## 資料來源說明

題庫內容來自官方考古題 PDF，每題的「解答」為正確選項（A/B/C/D）。原始 PDF 不含逐題文字詳解，因此目前不提供長篇解析；若日後有詳解檔可再併入。
